## Deviations from the approved plan
- The validator and the stack reader are one module, `environment_config.py` (subcommands `validate`, `export`, `get`, `from-stack`), because they share the schema and one import path keeps tests simple.
- Shared steps are composite actions, not reusable workflows (ADR-004, decision 2).
- The best-effort Supabase "recent backup" API check was dropped. The release requires the `backup_confirmed` input instead, because the API call could not be verified offline and a guess would be worse than an explicit human confirmation.
- The old Test-only assertion "the word live never appears in `deploy-test.yml`" became "Test workflow only targets Test": no `LIVE_`, no `/air-concepts/live`, no Live GitHub environment, every setup step is `environment: test`. The intent is kept and the check is stricter about what matters.
