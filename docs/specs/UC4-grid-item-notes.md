# UC4 forecast grid item notes

Approved by the human on 25 November 2026 for the invoice and bill rows in the forecast grid.

Each forecast item has its own internal note, displayed next to its label, with an action to add or edit it. Saving a blank note removes it. Notes belong to the underlying document, remain attached when its forecast month changes, and do not affect other items. They are visible and editable only within the authorised organisation and are not sent to Xero. Existing forecast note limits and access controls apply. Split amounts of the same document share the document's note.

Acceptance: users can add, view, edit and remove notes independently for different items; notes survive reload; failures retain the draft; and organisation access is enforced by the server.
